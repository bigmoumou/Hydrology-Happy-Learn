1.1 水文學之定義

水文學在研究什麼？

水文學（hydrology）屬於地球科學，研究地球上水的發生、循環、分佈、物理與化學特性，以及水和所有生物之間的關係。

工程水文學 engineering hydrology

屬於應用地球科學：用水文學原理，解決人類開發水資源時碰到的工程問題。它模擬水文循環中水體總量與時間分佈的關係，作為工程設計的標準，並評估設施面臨的風險。

1.2 水文循環 hydrologic cycle

水不停地在循環

地球上的水在大氣、土壤與海洋之間連續循環。

最簡單的版本：海面的水吸收太陽能蒸發進入大氣 → 水蒸氣凝結（condensation）成降水 → 以雨、雪、霜落到地表 → 受重力影響經河溪流回海洋。

漫地流 → 地表逕流

沒有入滲的雨在地表漫流，叫漫地流（overland flow）。

漫地流經過河川網路系統、進入河川之後，叫地表逕流（surface runoff）。粒子沿著山坡往低處匯集，進入溪流、河川，最後流入海洋。

中間流 interflow

滲入地表的水，在還沒深達地下水位之前，就在淺層側向流動、流出地面進入河川，叫中間流。

通往地下水 · 7–8 / 11

滲漏 → 地下水

有些水直接往深處滲漏（percolation），穿過未飽和層，到達地下水位以下。

在地下水層中流移、最後進入河川（或海洋）的水，叫地下水（groundwater）。它流得很慢，所以久旱不雨時河川仍然有水——第 2 章會叫它「基流」。

出滲 exfiltration

當表層土壤乾燥時，土壤裡的水由下層往上傳輸到地表，叫出滲。

方向和入滲相反：入滲是地表 → 土壤，出滲是土壤 → 地表。

汽體傳輸 · 10–11 / 11

蒸發與蒸散

蒸發（evaporation）：日照旺盛時，土壤或水面（窪蓄、河川、湖泊、海洋）的水分子吸收太陽能，由液態轉為汽態。

蒸散（transpiration）：土壤中的水經植物根系上傳到莖葉，再散失到大氣中。課本圖 1-2 把兩者合起來寫成蒸發散 ET。

小結

這個單元的三件事

  1. 水文學研究水的發生、循環與分佈；工程水文學用它來定設計標準、評估風險。
  2. 雨落地後分成地表（截留、窪蓄、漫地流）與地下（入滲 → 中間流、滲漏 → 地下水）兩條路，最後匯成河川流量。
  3. 汽體傳輸只有蒸發、蒸散；降水、漫地流、入滲、出滲、中間流、地下水是液體傳輸。
